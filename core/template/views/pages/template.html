🧠 How it works TemplateCore holds state and emits events.
TemplateUI listens and updates the DOM.
TemplateRouter drives tab switching via data-route attributes.
TemplateApp bootstraps all three on DOMContentLoaded.

📖 Developer Guide

1. Register a new route Open static/template/js/pages/main.js and call:
TemplateRouter.register('/myview', { viewId: 'tpl-view-myview', title: 'My View' })
2. Add a nav button In this file, add a button with data-route="/myview" and class tpl-nav-btn inside the .tpl-nav element.
3. Add a view section Add <section class="tpl-view" id="tpl-view-myview"> inside .tpl-right-panel below the existing views.
4. Update the Blueprint In core/template/__init__.py, add Flask routes for any backend endpoints your new view needs.
5. Add styles Create a new .css file in static/template/css/components/ and import it at the bottom of static/template/css/style.css.

🔗 Global APIs Available in Every Module

User & Auth window.__SERVER_USER__ — Authenticated user from Flask session
window.__USER_PERMISSIONS__ — User permissions array
window.__USER_SESSION__ — Boolean session state
window.__SERVER_ROUTE__ — Current server route string
window.hasPermission(perm) — Permission guard helper
window.DB.getCurrentUser() — Client-side user state
UI Utilities window.showToast(msg, type, duration) — Toast notifications
window.ThemeManager — Dark/light theme controller
window.Loader — Page loading state manager
Template Module Globals (this core) window.TemplateCore — State & event bus
window.TemplateUI — DOM helpers & view switcher
window.TemplateRouter — In-page hash routing
window.TemplateMainPage — Page-level logic
window.TemplateApp — Bootstrap controller
